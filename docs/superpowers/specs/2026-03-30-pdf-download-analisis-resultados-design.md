# PDF Download — Análisis de Resultados

**Date:** 2026-03-30
**Scope:** Add a "Descargar PDF" button to the Análisis de Resultados tab that generates a full clinical report for the Conners 3 Parents test.

---

## Overview

The `AnalisisResultados` page surfaces seven clinical analysis sections for the Conners 3 Parents assessment. Clinicians need a printable, shareable PDF that captures all section data plus a patient header (name, age, test date). The PDF is generated client-side using `jsPDF` + `jspdf-autotable` — no backend required.

---

## Patient Info Fields

`patientName` (string) and `testDate` (ISO date string, default today) are added alongside the existing `age` field:

- Both live in `App.jsx` as `useState`, persisted to localStorage under `patientName-{activeTest}` and `testDate-{activeTest}`.
- Loaded from localStorage when `activeTest` changes. They persist across answer resets (only cleared when switching away from an active test).
- Two new inputs added to `ModuleNav` next to the existing age input: "Nombre:" (text) and "Fecha:" (date type).
- All three (`age`, `patientName`, `testDate`) are passed as props to `AnalisisResultados`.

---

## PDF Structure

Generated by `src/utils/generateResultadosPDF.js`, a pure function with signature:

```js
generateResultadosPDF({ answers, questions, age, patientName, testDate })
```

Triggers a browser download named `conners3-resultados-{patientName}-{testDate}.pdf`. `patientName` is sanitized for use in filenames (spaces and special characters replaced with dashes; falls back to `"paciente"` if empty).

### Sections (in order)

1. **Header**
   - Title: "Conners 3 – Reporte de Resultados"
   - Patient name, age, test date

2. **Análisis de Estilo de Respuesta**
   - Pairs table: Ítem A / score, Ítem B / score, Dif.
   - Total A and Total B with flag if A ≥ 7 and B ≥ 2
   - PI and NI raw scores with flag if ≥ 5

3. **Conteo de Síntomas DSM-5**
   - Two tables: TDAH Inatento (9 criteria) and TDAH Hiperactivo-Impulsivo (9 criteria)
   - Columns: Criterio, Ítem(s), Puntaje, May be Ind., Indicated, ✓
   - Threshold result per type (age-adjusted: ≥6 if age ≤16, ≥5 otherwise)
   - Combined flag if both thresholds met

4. **Trastorno de Conducta y Negativismo Desafiante**
   - Two tables: TC (15 criteria, threshold 3) and TND (8 criteria, threshold 4)
   - Columns: Criterio, Ítem, Puntaje, May be Ind., Indicated, ✓
   - Met/not met status for each

5. **Deterioro Funcional**
   - Single table: 3 items (106, 107, 108) with score and label

6. **Índice TDAH de Conners 3**
   - Raw scores row, transposition rules row, transposed scores row
   - Total transposed score and probability of ADHD classification (%)
   - This table has 11 columns — rendered in landscape orientation (`doc.setPage` / `orientation: 'landscape'`) or with reduced font size to fit

7. **Ítems de Tamizaje y Conducta Grave**
   - Three tables: Ansiedad (4 items), Depresión (4 items), Conducta Grave (6 items)
   - Flag rows where score ≥ 1; section-level flag if any item flagged

## Button

- Label: "⬇ Descargar PDF"
- Placement: top of `AnalisisResultados`, only rendered when `activeTest === 'conners-parents'`
- Styled using the app's existing button styles
- On click: calls `generateResultadosPDF(...)`, no confirmation dialog

---

## Scoring Logic

`generateResultadosPDF.js` replicates the scoring computations from each component inline (same constants: PAIRS, INATTENTIVE, HYPERACTIVE, CD_CRITERIA, ODD_CRITERIA, TRANSPOSE, PROBABILITY, etc.). The existing display components are not refactored — the duplication is intentional to keep the PDF generator self-contained.
